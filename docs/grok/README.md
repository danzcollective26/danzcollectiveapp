Danz Collective Dev (bot de Cursor) a partir del proyecto Grok «Danz app».

- `ANEXO-SEIS-transcripcion-hilo13.md`: diseño de SEIS.
- `ANEXO-PLANTILLA-JUEGOS-DANZ.md`: inventario de nombres, textos y frases de cada juego.
- `ANEXO-NOTAS-LECTURA-16-11.md`: notas del 16/11.

`docs/PLAN_MAESTRO_GROK_Y_ARCADANZ_2026-11-28.md`; las decisiones posteriores del
